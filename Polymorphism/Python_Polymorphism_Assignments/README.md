# Python Polymorphism Assignments (1-70)

Each assignment is in a separate folder under one main folder.
Every assignment contains `main.py`.

## Run
Open Command Prompt/VS Code in an assignment folder and run:
    python main.py

## Levels
1-10 Basic Polymorphism
11-20 Method Overriding
21-30 Duck Typing
31-40 Polymorphism with Functions
41-50 Operator Overloading
51-60 Advanced Polymorphism
61-70 Mini Projects

These are beginner-friendly reference implementations. You can modify names, values, and output as needed for your college assignment.
